## En un minuto

Hugging Face reúne modelos, conjuntos de datos y aplicaciones demostrativas. Saber encontrarlos no equivale a confirmar su idoneidad: es necesario examinar documentación, licencia, procedencia y limitaciones.

## Diferencias esenciales

- **Model:** recurso de aprendizaje automático preentrenado o adaptado para una tarea.
- **Dataset:** colección de datos con procedencia, composición y condiciones de uso.
- **Space:** demostración o aplicación interactiva que permite experimentar con una solución.
- **Transformers:** biblioteca para trabajar con arquitecturas y modelos compatibles.

## Antes de elegir un recurso

1. Verifica **tarea**, idioma, dominio y público de destino.
2. Lee la **Model Card** o la **Dataset Card**.
3. Comprueba licencia, limitaciones, sesgos y usos previstos.
4. Examina requisitos computacionales y condiciones de acceso.
5. Define qué prueba o comparación permitiría decidir si sirve para tu proyecto.
